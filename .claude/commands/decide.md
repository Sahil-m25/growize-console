Write a new decision file in `docs/decisions/` for: $ARGUMENTS

Follow the shape of the existing files exactly: the decision in one line as the title, then the
date and where it applies, then **Why**, **Rejected** (the alternatives, and why each lost), and
**Cost** (what this decision makes harder or more expensive). Add the row to `docs/DECISIONS.md`.

If this decision reverses or amends an earlier one, say which, and amend that file with a line
pointing forward — never silently edit what was decided before.
